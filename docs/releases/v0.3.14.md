테스트용 디버그 APK입니다.

## 이번 버전 (0.3.14)
- **사이드바 위치는 설정에서**: 사이드바를 끌어서 옮기는 기능을 없앴습니다. **설정 → 디자인 설정 → 사이드바 위치**에서 고르고 오른쪽 위 ‘저장’을 누르세요.
  - 왼쪽(기본): 넓은 패널에 층수 릴 + 주차 영상
  - 오른쪽: 좁은 패널에 층수 릴만(영상 없음)
- **릴에서 고른 층이 더 잘 보이게**: 가운데 띠 밖의 층수를 조금 흐리게 했습니다(바로 옆 층 50%, 두 칸 떨어진 층 30%).
- 패널 맨 위의 이동 손잡이(짧은 막대)를 없애 그만큼 릴이 넓어졌습니다.

## 확인 방법
- 설정 → 디자인 설정을 펼치고 아래쪽 ‘사이드바 위치’에서 오른쪽을 고른 뒤 저장 → 홈의 층수 카드를 눌러 오른쪽에 좁은 패널(영상 없음)이 뜨는지 확인
- 다시 왼쪽으로 바꾸면 넓은 패널과 주차 영상이 돌아옵니다
