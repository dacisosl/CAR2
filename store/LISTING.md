# Google Play 스토어 등록 정보

Play Console → 앱 → 스토어 등록정보(기본, 한국어 ko-KR)에 그대로 붙여 넣는다. 글자 수는 Play 제한 기준(2026-10-04 확인).

## 앱 이름 (30자 이내)

```
주차기록 - 층수 자동 기록
```

15자. 다른 후보: `주차기록`, `주차기록: 내 차 몇 층?`
Play 메타데이터 정책상 이름에 ‘최고’, ‘무료’, ‘1위’, 이모지, 다른 회사 이름(네이버·현대 등)을 넣지 않는다.

## 간단한 설명 (80자 이내)

```
차에서 내리면 앱이 바로 떠요. 층수를 릴로 저장하고 상태바·위젯에서 확인하세요.
```

45자.

## 자세한 설명 (4,000자 이내)

```
지하 주차장에서 내 차가 몇 층이었는지 헷갈린 적 있나요?
주차기록은 차에서 내리는 순간 층수를 기록하도록 도와주는 앱입니다.

■ 차에서 내리면 바로 기록
· 내 차량의 Bluetooth 연결이 끊기면 알림을 누르지 않아도 앱이 바로 열려요.
· 이어폰·시계 연결에는 반응하지 않고, 등록한 차량만 확인해요.
· 시동만 잠깐 껐다 켠 경우처럼 바로 다시 연결되면 기록하지 않아요.

■ 층수는 릴을 돌려 한 번에
· 세로 릴을 돌려 B3·B2·1F·3F를 고르고 저장하면 끝. 바깥을 눌러 닫아도 마지막에 고른 층으로 저장돼요.
· 사이드바는 설정에서 왼쪽(주차 영상과 함께)이나 오른쪽(층수 릴만)으로 고를 수 있어요.
· 같은 주차장에서 최근 확인한 층이 있으면 기압 센서로 층수를 추천해요. 근거가 부족하면 추측하지 않고 직접 고르게 해요.

■ 앱을 열지 않아도 보이는 층수
· 저장한 층수를 상태바에 B2 표지판으로 띄워요. 층마다 검정·버건디·초록 바탕으로 구분돼요.
· 집 근처 주차는 상태바 표시가 기본으로 켜지고, 다른 곳은 기록할 때 켜고 끌 수 있어요.
· 홈 화면 위젯(1×1, 2칸)으로 층수·위치·경과 시간을 바로 확인해요.

■ 주차한 지 얼마나 됐는지
· 경과 시간이 2시간부터 초록, 3시간부터 버건디로 바뀌어요.

■ 사진과 위치
· 기둥 번호·구역 표지판을 사진으로 남기고 크게 확인해요. 다시 찍거나 삭제할 수 있어요.
· 위치 아이콘 한 번으로 지금 위치를 주차 위치로 저장해요.
· 저장한 주차 위치와 현재 위치를 지도에서 함께 확인해요.

■ 5가지 디자인
· 그래파이트 · 포레스트 · 에스프레소 · 실버, 그리고 블랙·네온 핑크의 다크 디자인 UHD 중에서 골라요.

■ 개인정보
· 계정·로그인이 없어요. 광고와 앱 안 결제도 없어요.
· 주차 기록, 사진, 위치, 등록 차량 정보는 이 휴대폰에만 저장돼요. 개발자 서버로 보내지 않아요.
· 지도를 표시할 때만 지도 제공 서비스에서 지도 데이터를 받아요.

■ 자동 표시를 위한 설정
차에서 내릴 때 앱이 바로 뜨려면 ‘근처 기기’ 권한과 ‘다른 앱 위에 표시’ 허용이 필요해요. ‘다른 앱 위에 표시’는 앱 화면을 바로 여는 데만 쓰고, 다른 앱 위에 창을 띄우지 않아요. 설정 → 자동설정 관리에서 현재 상태를 확인하고 바로 이동할 수 있어요.
· 휴대폰 설정에서 앱을 ‘강제 중지’하면 다음에 앱을 직접 열 때까지 자동 기록이 멈춰요.
· 일부 제조사의 절전 기능이 백그라운드 감지를 막을 수 있어요.
```

> 지도 문구: 현재 play 빌드는 `android/local.properties`의 네이버 지도 키로 빌드되어 지도가 표시된다. 키 없이 빌드하면 ‘저장한 주차 위치와 현재 위치를 지도에서…’ 줄과 ‘지도를 표시할 때만…’ 줄을 지운다.
> 상표: 설명에는 ‘네이버’ 이름이나 로고를 쓰지 않았다. 꼭 밝혀야 하면 ‘지도 데이터: 네이버 지도’처럼 사실 표기 한 줄만 쓰고 로고·브랜드 색은 쓰지 않는다. ‘Bluetooth’는 기능 설명을 위한 단어로만 쓴다.
> 0.3.12의 사이드바 주차 영상·각인 애니메이션은 설명 문구를 바꿀 필요는 없다. 스크린샷 03은 다시 찍는다(아래).

### 다시 캡처하는 방법

1. **play 빌드 0.3.12**(지도 키 포함)를 에뮬레이터나 실제 휴대폰에 설치한다(github 빌드는 ‘업데이트 확인’ 버튼이 보이므로 쓰지 않는다).
2. 포레스트 테마, 주차 기록 B2, 사진 있는 차량 카드, 지도에 P 핀이 보이는 상태로 아래 4장을 캡처한다(1080×1920 이상 세로 화면).
   - `store-home-forest.png`: 홈(지도 표시)
   - `store-drawer-forest.png`: 층수 패널(영상·릴 보이게)
   - `store-themes.png`: 설정 → 디자인 설정 펼침(5종)
   - `store-settings-top.png`: 설정 → 자동설정 관리
3. `%TMP%\claude\shots\`에 넣고 `python tools/store_assets.py feature screens` 실행 → 02~06과 그래픽 이미지가 다시 만들어지고 규격 확인이 자동으로 돈다.
4. 지도 화면의 네이버 로고·저작권 표시는 SDK 이용 조건이므로 지우거나 가리지 않는다. 실제 주소가 드러나는 곳(집 근처)은 피해서 찍는다.
5. 가짜 화면을 그리지 않는다. 실제 캡처만 쓴다.
