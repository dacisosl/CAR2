# 앱 디자인 명세

버전 1.2 · 2026-10-03 · CAR는 가칭, 한국어 서비스명은 주차기록.

## 디자인 방향

정보를 빠르게 읽는 차량 보조 앱. 넓은 화이트 여백, 큰 층수, 명확한 주차 시간, 간결한 차량 실루엣. 헤이딜러에서 사용자가 설명한 단순함과 세련됨을 방향으로 삼되 별도 브랜드 에셋을 사용한다. 고급스러움은 과한 장식보다 글자 비율, 정렬, 여백에서 만든다.

## 시각 기준 — 기본 클래식 테마

| 항목 | 기준 |

| 터치 영역 | Android 구현에서 최소 48×48dp. 카메라는 그림만 작게 표시 |

설정에서 클래식(블랙·화이트)과 스틸 포인트(얇은 실버 디테일)을 선택한다. 신규 설치 기본값은 클래식이고 선택을 즉시 적용·영속 저장한다. 스틸 포인트도 화이트 화면·블랙 글자를 유지하고 얇은 실버 테두리와 작은 각진 디테일만 더한다. 세부 규칙은 `THEME_DESIGN.md`, 두 테마 토큰은 `design/tokens.json`을 따른다. 이후 이 문서의 화이트·검정 면 설명은 클래식 기준이며 정보 구조·동작·터치 영역은 두 테마 공통이다.

색은 계층과 명암으로 사용한다. 앱 UI에 네이비·금색·새 포인트 색을 추가하지 않는다. 실제 기본 지도의 공원·도로 색은 지도 데이터의 색으로 유지할 수 있다. 큰 글자 배율에서도 잘리지 않게 하고 작은 글자로만 정보를 전달하지 않는다.

## 로고·차량

- `assets/logo/car-logo.png`: 굵은 CAR 워드마크, R 안의 차량 형상, 작은 주차기록 표기.
- `assets/vehicle/car-side.png`: 사용자 이미지2 맨 위 방향의 간결한 측면 실루엣. 지붕선·차체·두 바퀴만 사용한다.
- 클래식의 두 에셋은 투명 PNG다. 스틸 포인트의 차량은 `assets/vehicle/car-steel.svg`를 사용하고 로고는 동일한 블랙을 유지한다. 사용자 사진은 그대로 표시한다. 클래식 PNG는 실제 SVG나 Android VectorDrawable이 아니다. 크기를 강제로 늘리거나 투명 여백까지 카드 폭을 채우지 않는다.
- 헤더에는 폭 92~112dp의 로고를 배치한다. 로고 원본 비율을 유지하고 실제 시각 영역을 기준으로 정렬한다.
- 차량은 흰색 또는 옅은 회색 면에서 검정으로 사용한다. 상세 렌더링, 제조사 엠블럼, 그릴·문손잡이를 추가하지 않는다.
- 런처용 adaptive icon은 Android 단계에서 이 브랜드 방향으로 별도 제작한다. 가로 워드마크를 그대로 아주 작게 축소해 넣지 않는다.

## 홈 화면

1. 시스템 상태 표시 영역과 안전 여백.
2. 왼쪽 CAR 로고, 오른쪽 Bluetooth 아이콘과 설정 아이콘.
3. ‘주차한 지’ 보조 라벨, ‘2시간 13분’ 경과 시간.
4. 왼쪽 층수 카드, 오른쪽 차량 카드. 층수 카드는 검정 면·흰 B2. 차량 카드는 옅은 회색 면과 검정 측면 아이콘.
5. 위치명과 구역 메모. 예시 값은 ‘센트럴 주차장’, ‘C구역 · 24번’이며 실제 위치가 아니다.
6. 아래 공간을 넓게 사용하는 단순한 밝은 지도. 검정 P 주차 핀·층수 배지, 최신 현재 위치 점, 작은 재중앙 버튼. 첨부 지도 참조의 색·정보량을 SDK 커스텀 스타일로 반영한다. `MAP_DESIGN.md`를 따른다.

‘내 차 위치 보기’ 버튼, ‘기록 수정’ 버튼, ‘자동 기록 켜짐’ 텍스트 줄은 없다. 층수 카드 탭으로 패널을 다시 열 수 있다. 지도 자체의 이동·확대 제스처로 위치를 확인한다.

Bluetooth 아이콘의 활성은 검정 심볼과 옅은 회색 채움, 비활성은 옅은 회색 심볼로 구분한다. 이 아이콘은 **자동 기록 준비 상태**를 나타낸다. 실제 차량 연결 여부와 혼동하지 않도록 접근성 이름과 설정 상세에서 구분한다. 네이티브 권한·감지 준비가 안 되었으면 활성으로 표시하지 않는다.

사진이 있으면 차량 카드를 사진 미리보기로 바꿀 수 있다. 사진 보기와 사진 교체는 이 영역 및 사이드바 카메라 버튼에서 처리한다. 홈에 새로운 버튼 행을 추가하지 않는다.

## 사이드바

- 기본 위치는 왼쪽. 사용자가 마지막에 선택한 왼쪽/오른쪽 위치를 저장한다.
- 작은 화면의 기본 폭은 약 200~216dp, 실제 화면 폭의 60% 이내. 일반적인 390dp 화면에서는 약 52~55%를 사용한다. 큰 글자에서는 필요한 폭을 확보한다.
- 패널 면은 불투명 화이트. 뒤의 홈만 옅게 어둡게 한다.
- 패널 높이는 화면 전체가 아니라 약 540dp(큰 글자 배율만큼 증가, 화면의 90% 이내)로 세로 가운데에 둔다. 안쪽 모서리는 둥글게.
- 패널 바깥(어둡게 한 홈)을 누르거나 뒤로 가기를 하면 릴에서 마지막으로 멈춘 층으로 저장하고 닫는다. 고른 층이 없거나 기존 기록에서 바뀐 것이 없으면 저장 없이 닫는다. 닫기(X)는 저장하지 않고 닫는다. (2026-10-03 사용자 결정)
- 상단: 이동 손잡이 → ‘주차 층수’와 닫기 → 추천 문구.
- 중앙: 세로 릴. 순서는 높은 지상층 → 1F → B1 → B2 → 더 깊은 지하층. 0F는 만들지 않는다.
- 가운데 한 항목을 검정 선택 띠·흰 글자로 강조한다. 가까운 층은 보조 명암, 먼 층은 흐리게 표현한다. 선택 시 한 층 단위 스냅과 가벼운 햅틱.
- 네이티브 릴: 항목 60dp, 층 사이 구분선. 글자는 중앙에서 멀어질수록 연속적으로 작아지고 흐려진다. 띠 경계에서 글자색이 정확히 갈리도록 띠 안·밖을 따로 그린다. 놓으면 시스템 관성 후 스프링으로 가까운 층에 맞춘다. 손으로 돌리는 동안 중앙 층이 곧바로 선택값이 된다.
- 층수 범위는 건물 설정에 따라 확장한다. 브라우저 데모는 6F~B6이다.
- 하단: **카메라 아이콘만 있는 정사각형 버튼 + ‘저장’ 작은 직사각형 버튼**, 한 줄 두 열. 두 버튼 모두 패널 내부에 있어야 한다.
- 카메라 글자 ‘사진 추가’를 표시하지 않는다. 접근성 이름은 ‘주차 사진 추가’로 제공한다.
- 네이티브 기본 크기: 카메라 터치 영역 48dp, 저장 88~96×48dp, 간격 10~12dp. 공간이 부족하면 패널 폭을 조정하고 바깥으로 넘기지 않는다.

## 좌우 이동 제스처

상단 손잡이를 약 350ms 길게 눌러 이동을 시작한다. 드래그 동안 반대쪽 고정 위치를 표시한다. 반대쪽 가장자리 근처에서 놓으면 해당 쪽에 스냅하고 햅틱을 준다. 유효 영역 밖에서 놓으면 원래 쪽으로 복귀한다. 릴이나 카메라·저장 버튼에서 위치 이동을 시작하지 않는다. 설정에서도 왼쪽/오른쪽을 선택할 수 있다. RTL 언어에서도 저장 값은 물리적 왼쪽/오른쪽으로 정의한다.

## 추천과 기록 상태

- 충분한 근거: ‘B2로 예상돼요’, 해당 층을 릴 중앙에 제안.
- 근거 부족: ‘층수를 선택해주세요’. 과거 선택값은 자동 측정 결과처럼 표시하지 않는다.
- 센서 없음: 수동 릴 그대로 사용. 설정 상세에서 기압 추천 미지원 안내.
- 저장: 사용자의 최종 층수·사진·원래 감지 시각을 기록하고 패널을 닫음.
- 닫기: 후보를 확정하지 않음. 기존 확정 기록 유지.
- 아직 기록 없음: 시간·층수·위치에 실제 값처럼 보이는 데모 숫자를 넣지 않음. 층수 카드를 통해 수동 시작 안내.

## 첫 시작과 설정

화이트 면, CAR 로고, 작은 측면 차량 아이콘, ‘주차 위치를 / 쉽게 기억하세요’, 짧은 설명. 하단 ‘내 차량 연결하기’와 ‘나중에 설정’.

설정 흐름은 차량 선택 → 필요한 권한과 실행 조건 → 자동 화면 표시 테스트 순서다. 여러 권한 설명을 한 번에 길게 늘어놓지 않는다. 현재 기기에서 실제로 필요한 단계만 보여준다. Bluetooth, 위치, 알림/감지 서비스, 다른 앱 위에 표시, 제조사 실행 설정 등을 상황에 맞게 확인한다. Android 사진 선택기를 쓸 수 있으면 전체 사진 보관함 권한을 일괄 요청하지 않는다.

## PNG 읽는 법

`design/app-design-final.png`는 클래식의 구성과 스타일 기준이다. `design/app-design-steel-sample.png`는 블랙·화이트 + 스틸 포인트 샘플이다. 테마 선택의 최종 동작은 `THEME_DESIGN.md`를 따른다. 생성형 시안의 미세한 글자 간격과 자산 모양은 실제 에셋·토큰으로 정리한다. 지도는 예시다. 실제 앱에는 지도 SDK와 실제 좌표를 넣는다. 네이티브 터치 영역·접근성·동적 글자 기준이 PNG의 픽셀보다 우선한다.

## 최신 지도 반영 시안

`design/app-design-map-v1.2.png`가 최신 통합 시안이다. 지도는 클래식·스틸 포인트 모두 같은 밝은 스타일이다. 참조에 있는 점선 경로와 도보 시간은 실제 경로 API를 도입한 다음 단계에 표시한다. 지도 색은 공원·위치 상태 표현에만 사용하며 앱의 블랙·화이트 로고와 버튼은 유지한다.
