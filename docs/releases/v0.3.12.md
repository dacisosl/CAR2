테스트용 디버그 APK입니다.

## 이번 버전 (0.3.12)
- **주차 장면이 들어간 층수 패널**: 패널을 화면 폭의 90%까지 넓혀 왼쪽은 층수 릴, 오른쪽은 차가 기둥 옆에 후진 주차하는 영상(5초, 한 번 재생)으로 나눴습니다. 영상은 고른 디자인 색으로 다시 칠해집니다(UHD는 어두운 바탕에 밝은 선).
- **기둥에 층수 새기기**: 층을 고르면 기둥 표지판이 층 색(검정·버건디·초록)으로 차오르고, 흰 층 글자가 왼쪽부터 새겨진 뒤 빛이 훑고 모서리에 별빛이 반짝입니다. 영상 도중에 골라도 글자는 움직이는 표지판을 따라가고, 차가 다 들어오면 표지판 쪽으로 다가가 릴의 선택 띠와 같은 높이에 글자가 옵니다. 휴대폰의 ‘애니메이션 삭제’ 설정에서는 주차가 끝난 정지 장면만 보입니다.
- **카드 높이**: 홈의 ‘주차 층수’와 ‘내 차량’ 카드 높이가 항상 같습니다.
- **하차 위치가 지도에 반영**: 시동을 끄고 내린 위치를 저장 후에도 끝까지 받아 기록과 지도에 넣고, 위치가 들어오면 지도가 그 자리로 이동합니다.
- **지도 테두리**: 지도에 은은한 그림자와 얇은 테두리를 넣어 카드와 자연스럽게 구분했습니다.
- **더 빠른 자동 표시**: 하차 순간의 처리 순서를 줄이고, 창 열림 애니메이션 없이 바로 패널을 띄웁니다.
- **가로·작은 화면**: 높이가 모자라면 주차 장면이 비율을 지켜 줄어들어 닫기 버튼이나 안내 문구를 가리지 않습니다.
- **안정성**: 열린 패널 위에 ‘층수를 기록하세요’ 알림이 남던 문제, 자동 표시 뒤 잠금 화면 위 표시가 꺼지지 않을 수 있던 문제, 저장 중 릴·닫기 입력으로 고른 층이 바뀌거나 사라지던 문제, 사진 저장이 늦게 들어온 주차 위치를 덮던 문제, 시계가 뒤로 맞춰지면 ‘운전 중’이 표시되지 않던 문제를 고쳤습니다.
- **Play 배포판 정리**: 앱 안 업데이트(GitHub에서 내려받기)는 이 GitHub 배포판에만 들어가고 Play 빌드에서는 코드째 빠집니다.

## 확인 방법
- 홈의 층수 카드를 눌러 패널을 열면 영상이 재생됩니다. 릴에서 층을 고르면 기둥 표지판에 새겨집니다.
- `adb logcat -s VehicleEvent` — 시동 끄기 → `candidate … shown immediately, launch=true`.

## 아직 실차·실기기에서 확인할 것
- 하차 자동 표시 체감 속도, 시동만 껐다 켰을 때 패널이 닫히는지
- 저사양 기기에서 영상 재생과 새기기 애니메이션이 끊기지 않는지
- 하차 위치가 지하 주차장에서 늦게 잡힐 때 기록·지도에 채워지는지
