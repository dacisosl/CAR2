# Play Console 데이터 보안(Data safety) 응답 초안

Play Console → 앱 콘텐츠 → 데이터 보안. 아래는 **play 빌드**(`bundlePlayRelease`, 앱 안 업데이트 없음) 기준이다.

Google 기준에서 ‘수집’은 기기 밖으로 전송하는 것을 뜻한다. 휴대폰 안에서만 처리·저장하는 데이터는 수집으로 신고하지 않는다.

## 1. 지도 키가 없는 빌드 (현재 상태)

| 질문 | 응답 |
|---|---|
| 앱이 필수 사용자 데이터 유형을 수집하거나 공유하나요? | **아니요** |
| 이유 | 위치·사진·기기 주소·주차 기록 모두 휴대폰 안에서만 저장·처리. 서버 없음, 광고·분석 SDK 없음 |

## 2. 네이버 지도 키를 넣은 빌드

지도 화면을 그리면 네이버 SDK가 지도 데이터를 요청한다. 네이버가 공개한 SDK 데이터 처리 내용을 확인한 뒤 아래를 기준으로 답한다.

| 데이터 유형 | 수집 | 공유 | 목적 | 비고 |
|---|---|---|---|---|
| 위치 › 대략적인 위치 | 예(SDK가 지도 영역 요청 시) | 아니요 | 앱 기능 | 처리 후 저장 여부는 네이버 고지 확인 |
| 앱 활동 / 기기 또는 기타 ID | SDK 고지에 따름 | 아니요 | 앱 기능·분석(SDK) | 네이버 지도 SDK 문서 확인 |

공통 응답:
- 전송 중 데이터 암호화: 예(HTTPS)
- 사용자가 데이터 삭제를 요청할 수 있음: 앱 삭제로 전부 삭제(서버 저장 없음)
- 데이터 수집이 필수인가요: 지도 표시에 필요. 지도 없이도 층수·사진 기록은 가능

## 3. 기타 앱 콘텐츠 항목

| 항목 | 응답 |
|---|---|
| 광고 포함 | 아니요 |
| 앱 액세스 | 모든 기능 로그인 없이 이용 가능. 심사 안내 문구는 `PLAY_CONSOLE_CHECKLIST.md`의 ‘앱 액세스’ 참고 |
| 콘텐츠 등급 | 설문: 유틸리티. 폭력·성적 콘텐츠·도박·사용자 간 소통·위치 공유 모두 ‘아니요’. 위치를 다른 사용자와 공유하지 않음 |
| 타겟층 | 18세 이상(또는 13세 이상). 아동 대상 아님 |
| 뉴스 앱 / 정부 앱 / 금융 / 건강 | 아니요 |
| 개인정보처리방침 | https://github.com/dacisosl/CAR2/blob/main/docs/PRIVACY_POLICY.md |
