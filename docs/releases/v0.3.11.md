테스트용 디버그 APK입니다.

## 이번 버전 (0.3.11)
- **하차 즉시 표시**: 시동을 끄면 재연결 확인을 기다리지 않고 **바로** 층수 패널이 뜹니다. 재연결 확인(2초)은 패널을 띄운 뒤 뒤에서 하고, 시동만 껐다 켠 경우에는 열린 패널이 저장 없이 저절로 닫힙니다.
- **릴 선택 띠**: 패널을 열자마자 가운데 띠가 검게 채워져 지금 어느 층을 가리키는지 보입니다. 릴을 움직이지 않고 **저장**을 누르면 띠에 있는 층으로 저장합니다(바깥을 눌러 닫을 때는 직접 고른 층만 저장).
- **운전 중 표시**: 차량 Bluetooth가 연결되면
  - 앱: ‘주차한 지’ 대신 **운전 중**과 연결된 뒤부터 센 시간(0부터 다시 셈)
  - 위젯: 층수·시간 대신 검은 표지판의 **차량 아이콘**과 ‘운전 중’
  - 상태바: 층 표지판 대신 **차량 표지판**과 ‘운전 중’(마지막 기록에서 상태바를 켜 둔 경우)

## 확인 방법
`adb logcat -s VehicleEvent` — 시동 끄기 → `candidate … shown immediately, launch=true`. 2초 안에 다시 켜면 → `vehicle reconnected within check window — candidate cancelled`.

## 아직 실차에서 확인할 것
- 하차 즉시 표시 체감 속도, 시동만 껐다 켰을 때 패널이 닫히는지
- 운전 중 위젯·상태바 표시(에뮬레이터는 차량 Bluetooth 연결을 만들 수 없음)
