# Google Play 스토어 등록 정보

Play Console → 앱 → 성장 → 스토어 등록정보 → 기본 스토어 등록정보(한국어)에 그대로 붙여 넣는다. 글자 수는 Play 제한 기준.

## 앱 이름 (30자 이내)

```
주차기록 - 층수 자동 기록
```

다른 후보: `주차기록`, `주차기록: 내 차 몇 층?`

## 간단한 설명 (80자 이내)

```
차에서 내리면 앱이 바로 떠요. 층수를 릴로 저장하고 상태바·위젯에서 확인하세요.
```

## 자세한 설명 (4,000자 이내)

```
지하 주차장에서 내 차가 몇 층이었는지 헷갈린 적 있나요?
주차기록은 차에서 내리는 순간 층수를 기록하도록 도와주는 앱입니다.

■ 차에서 내리면 바로 기록
· 내 차량의 Bluetooth 연결이 끊기면 알림을 누르지 않아도 앱이 바로 열려요.
· 이어폰·시계 연결에는 반응하지 않고, 등록한 차량만 확인해요.
· 시동만 잠깐 껐다 켠 경우처럼 바로 다시 연결되면 기록하지 않아요.

■ 층수는 릴을 돌려 한 번에
· 세로 릴을 돌려 B3·B2·1F·3F를 고르고 저장하면 끝.
· 사이드바는 손잡이를 길게 눌러 왼쪽·오른쪽으로 옮길 수 있어요.
· 같은 주차장에서 최근 확인한 층이 있으면 기압 센서로 층수를 추천해요. 근거가 부족하면 추측하지 않고 직접 고르게 해요.

■ 앱을 열지 않아도 보이는 층수
· 저장한 층수를 상태바에 B2 표지판으로 띄워요.
· 집 근처 주차는 상태바 표시가 기본으로 켜지고, 다른 곳은 기록할 때 켜고 끌 수 있어요.
· 홈 화면 위젯(1×1, 2칸)으로 층수·위치·경과 시간을 바로 확인해요.

■ 주차한 지 얼마나 됐는지
· 경과 시간이 2시간부터 초록, 3시간부터 버건디로 바뀌어요.

■ 사진과 위치
· 기둥 번호·구역 표지판을 사진으로 남기고 크게 확인해요.
· 위치 아이콘 한 번으로 지금 위치를 주차 위치로 저장해요.

■ 4가지 디자인
· 그래파이트 · 포레스트 · 에스프레소 · 실버 중에서 골라요.

■ 개인정보
· 계정·로그인이 없어요.
· 주차 기록, 사진, 위치, 등록 차량 정보는 이 휴대폰에만 저장돼요. 서버로 보내지 않아요.

■ 자동 표시를 위한 설정
차에서 내릴 때 앱이 바로 뜨려면 ‘근처 기기’ 권한과 ‘다른 앱 위에 표시’ 허용이 필요해요. 설정 → 자동설정 관리에서 현재 상태를 확인하고 바로 이동할 수 있어요.
· 휴대폰 설정에서 앱을 ‘강제 중지’하면 다음에 앱을 직접 열 때까지 자동 기록이 멈춰요.
· 일부 제조사의 절전 기능이 백그라운드 감지를 막을 수 있어요.
```

> 지도: 네이버 지도 키를 넣은 빌드에서만 ‘지도’ 관련 문구를 추가한다. 키 없는 빌드는 지도가 ‘미연결’로 보이므로 설명에 지도 기능을 쓰지 않는다.
