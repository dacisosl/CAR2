# 최신 결정 기록

2026-10-03까지의 사용자 지시를 정리했다.

| 결정 | 현재 기준 |
|---|---|
| 플랫폼 | Android |
| 앱 이름 | 한국어 주차기록, CAR는 영문 가칭 |
| 레이아웃 | 사용자의 원래 홈 레이아웃 정보 순서 유지·최적화 |
| 색상·테마 | 기본 클래식은 블랙·화이트. 설정에서 스틸 포인트(얇은 실버 디테일) 선택 가능, 선택 저장 |
| 로고 | 굵은 영문 CAR와 R 내부 차량 형상, 주차기록 descriptor |
| 차량 | 클래식은 기존 측면 실루엣, 스틸 포인트는 간결한 각진 블랙 측면 심볼과 작은 실버 선 |
| 홈 버튼 | ‘내 차 위치 보기’, ‘기록 수정’ 삭제 |
| BT | 설정 옆 아이콘, 활성/비활성 시각 상태. 별도 상태 글자 줄 삭제 |
| 패널 | 기본 왼쪽(넓은 패널: 릴 + 주차 영상). 위치는 설정에서만 바꾸고 오른쪽은 좁은 패널에 릴만(영상 없음). 위치 저장 (2026-10-05 변경: 손잡이 드래그 삭제) |
| 층수 | 세로 릴 스크롤 |
| 사진·저장 | 카메라 아이콘만 + 작은 저장 버튼, 2열·1행, 패널 내부 |
| 자동 실행 | 사전 설정 후 앱 화면이 직접 자동 표시되어야 함 |
| 추천 | 기압과 현재 방문의 기준점으로 층수 제안, 사용자 확인 |
| 지도 | 새 참조의 단순한 밝은 스타일, 네이버 SDK 커스텀 스타일·P 핀·현재 위치·재중앙. 도보 안내는 다음 단계. 시안/프로토타입은 예시 |
| 첫 시작 | 로고·차량·짧은 설명과 간결한 설정 안내 |

## 되돌리지 않을 이전 안

- 네이비 브랜드 색, 상세 3/4 차량 일러스트, 기존 P 앱 로고.
- 홈 하단의 큰 위치보기 버튼과 기록 수정 링크.
- ‘자동 기록 켜짐’ 별도 텍스트 행.
- 사진 추가 텍스트가 붙은 큰 버튼, 저장과 세로로 쌓은 버튼.
- 패널 밖으로 넘치는 저장 버튼.
- 백그라운드에서는 반드시 알림을 눌러야 한다는 기본 흐름.

## 개발 기본값과 아직 실제로 확인할 항목

개발 기본값: Kotlin·Compose, 로컬 저장, 기본 2초 재연결 확인(2026-10-04, 6초에서 단축), 패널 기본 왼쪽, 가칭 CAR.

실제 확인: 테스트 휴대폰/OS, 등록 차량 장치와 profile, 기압 센서, 자동 표시 지원 조건, SDK/의존성 호환 버전, 지도 키·최신 사용 조건, 건물별 기준점·층간 높이. 이 항목을 이미 구현·검증된 것으로 취급하지 않는다.
