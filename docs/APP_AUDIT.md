# 앱 점검 결과 (0.3.3, 2026-10-03)

코드 전체를 별도 검토자가 읽기 전용으로 점검하고, 에뮬레이터(Android 15)에서 직접 확인한 결과다. 상태: ✅ 수정함 · ⏸ 보류(이유 기재) · 🔍 실기기 확인 필요.

## 확인된 정상 항목

버전별 API 분기(33+ 인텐트, 27+ 잠금 화면, 28+ ImageDecoder, 30+ 권한 자동 회수, 33+ 알림 권한), 모든 PendingIntent 불변 플래그, FileProvider 경로, Room 1→2 마이그레이션(0.2.0에서 덮어 설치해 기록 유지 확인), 외부 공개 수신기는 보호된 시스템 이벤트만 받음, 개인정보 로그 없음, 위치는 화면 사용 중에만.

## 에뮬레이터에서 직접 확인한 흐름 (0.3.1~0.3.3)

- GitHub 업데이트: 0.3.1이 실행 시 0.3.2를 자동으로 찾아 안내 → 내려받기(SHA-256·패키지·버전 확인) → ‘출처를 알 수 없는 앱’ 허용 화면까지. 허용 토글은 휴대폰 보안 설정이라 사용자 몫으로 남김.
- 사이드바 상태바 스위치 켜고 저장 → 상태바에 B2 표지판 표시.
- 설정 4개 메뉴, 저장 버튼 활성/비활성, 집 위치 등록·저장, 위치 저장 아이콘.
- 디자인 설정 펼침, 포레스트 적용.
