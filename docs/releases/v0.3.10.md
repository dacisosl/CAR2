## 이번 버전 (0.3.8 → 0.3.10)
- **차량 하차 감지 수정**: 시동을 끄면 **2초 안에** 층수 패널이 뜹니다. 백그라운드에서 확인 도중 앱이 정리돼 패널이 안 뜨던 문제와, 연결 신호를 놓치면 이후 해제가 무시되던 문제를 고쳤습니다.
- 재연결 여부는 Bluetooth 프로필 연결 목록에서 직접 확인합니다(2초 안에 다시 시동을 켜면 주차로 보지 않음).
- 홈에 차량 상태 한 줄: **차량 연결됨 · 이동 중** / **하차 감지 · 눌러서 층수 기록**. Bluetooth 아이콘은 연결 중일 때 채워집니다.
- 자동 표시가 막혀 열리지 않은 하차 후보는 앱을 열 때 한 번 패널로 올립니다.
- 사진 크게 보기에서 **다시 찍기 · 삭제**(확인 후).

## 0.3.8 이전에 포함된 변경
- 사이드바 바깥을 누르거나 뒤로 가기를 해도 릴의 마지막 층으로 저장
- 사이드바 높이 축소, 릴 스크롤 개선(연속 크기·명암, 구분선, 스프링 스냅)
- 상태바·위젯 층 표지판: 흰 글자 + 검정 → 버건디 → 초록 바탕 반복
- 다섯 번째 디자인 **UHD**(블랙·차콜 다크, 네온 핑크, 경과 시간 계기판)
