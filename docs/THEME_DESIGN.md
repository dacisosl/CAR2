# 디자인 테마 선택

버전 1.1 · 2026-10-03. 블랙·화이트를 기본으로 하고 스틸은 작은 포인트로만 사용한다. 설정에서 클래식과 스틸 포인트를 선택한다.

## 선택 화면

설정 → 디자인 테마. 미리보기 카드 두 개를 한 줄로 배치한다. 카드 전체를 누르면 선택하고 라디오 상태로 표시한다. 별도 저장 버튼 없이 즉시 적용한다. 두 미리보기 모두 밝은 블랙·화이트 바탕이다.

| 선택 | 클래식 | 스틸 포인트 |
|---|---|---|
| 화면 | 화이트 바탕, 차콜 글자 | 같은 화이트 바탕, 차콜 글자 |
| 카드·버튼 | 절제된 둥근 모서리 | 작은 모서리 반경과 일부 카드의 작은 사선 모서리 |
| 선택 층수·저장 | 검정 면과 흰 글자 | 같은 검정 면과 흰 글자, 얇은 실버 테두리 |
| 차량 | 간결한 블랙 측면 실루엣 | 간결한 각진 블랙 측면 심볼과 작은 실버 선 |
| 지도 | 참조에 맞춘 밝은 커스텀 스타일 | 같은 밝은 커스텀 스타일 |

신규 설치 기본값은 클래식. 시스템 다크 모드로 사용자 선택을 바꾸지 않는다. DataStore의 `appTheme=classic|steel`로 저장하고 앱 재실행·차량 이벤트 자동 진입에서도 먼저 테마를 복원한다. 이전 설정에 값이 없거나 모르는 값이면 클래식으로 처리한다.

## 공통 동작

홈, 좌우 사이드바, 처음 시작, 설정, 권한 안내에 같은 테마를 적용한다. 테마 변경은 확정 기록·층수·사진·감지 시각·자동 기록 설정·패널 위치·미저장 후보를 변경하지 않는다. 선택 후 설정 화면과 스크롤 위치를 유지한다. 릴 간격·정보 순서·최소 48dp 터치 영역은 동일하다.

Bluetooth 아이콘은 두 테마 모두 검정 활성, 회색 비활성이다. 접근성 상태 설명을 함께 제공한다. 카메라 아이콘과 작은 저장 버튼은 한 행이며 모두 패널 안에 들어간다. 사용자가 선택한 사진은 원색으로 유지한다.

## 스틸 포인트의 범위

각진 차체와 절제된 스테인리스 디테일에서 착안한 독자적인 테마다. 메뉴의 이름은 ‘스틸 포인트’다. 제조사 로고나 모델 공식 UI를 쓰지 않는다.

화이트 화면·패널, 블랙 글자·로고·차량·선택 면을 유지한다. 실버는 층수 카드·선택 릴·주요 버튼의 얇은 테두리와 작은 손잡이·차량 선에만 사용한다. 면적 비중은 대략 5~10% 이하를 목표로 한다. 배경이나 패널 전체를 금속으로 채우지 않는다. 큰 메탈 그라데이션·네온·복잡한 HUD·금속 글자를 사용하지 않는다. 텍스트 뒤는 평평한 면이다.

지도는 두 테마 모두 `MAP_DESIGN.md`의 밝은 커스텀 스타일이다. 지도 로고·저작권을 유지한다. 지도 전체를 필터로 반전시키거나 사진에 금속 필터를 입히지 않는다.

## 파일과 구현

- `design/app-design-final.png`: 클래식 구성 기준.
- `design/app-design-steel-sample.png`: 최신 블랙·화이트 + 스틸 포인트 샘플, 홈·왼쪽 패널·테마 설정·첫 시작. 원본은 1672×941px이다. UHD 디테일 무드를 요청한 시안이며 3840×2160px 원본으로 표기하지 않는다.
- `design/tokens.json`: 두 테마 기준. 상위 `colors`는 이전 클래식 호환용이며 신규 구현은 `themes`에서 선택한다.
- `assets/vehicle/car-steel.svg`: 블랙 차체와 작은 실버 선의 프로토타입용 측면 차량 벡터. Android에서는 VectorDrawable/Compose 경로로 옮긴다.
- `prototype/index.html`: 설정에서 두 테마를 직접 선택하는 브라우저 UI 데모.

Compose의 공통 `AppTheme`에서 색·형태를 제공한다. 테두리 디테일과 차량 심볼만 테마에 따라 바꾼다. 저장값을 복원한 후 최초 화면을 그려 다른 테마가 잠깐 나타나지 않게 한다. Android 구현·DataStore 저장·실기기 검증은 아직 포함되지 않았다.

버전 1.2 추가: 최신 통합 시안은 `design/app-design-map-v1.2.png`다. 기존 스틸 샘플은 금속 포인트·설정 화면 참고로 유지한다. 테마를 바꿔도 지도 위치·현재 위치·주차 핀은 초기화하지 않는다.
