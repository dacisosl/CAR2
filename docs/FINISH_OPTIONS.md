## 마감 제안

층수 카드·선택 띠·주요 버튼에 아주 약한 상단 하이라이트, 얇은 테두리와 낮은 그림자를 적용한다. 차량 심볼에는 단순한 작은 빛 선을 더할 수 있다. 글자 뒤의 반사 영역이 글자를 흐리게 하지 않게 한다. 큰 배경과 사이드바는 읽기 쉬운 평평한 면으로 유지한다.

무거운 크롬 테두리·과한 입체 효과 대신 일정한 빛 방향, 절제된 곡면 느낌, 덜 빽빽한 글자와 간격으로 정리한다. 이 제안은 디자인 판단이며 특정 팔레트의 우월성을 측정한 결과가 아니다. 표면의 깊이감은 빛과 그림자로 나타낼 수 있다는 일반 원칙은 [Fluent의 elevation 문서](https://fluent2.microsoft.design/elevation/)를 참고했다. 해당 디자인 시스템을 Android 전체에 도입하는 것은 아니다.

`design/gloss-palette-options.png`가 홈 화면 3가지 비교안이다. 내장 imagegen 제작, 원본 1672×941px. `docs/PALETTE_IMAGEGEN_PROMPT.md`에 프롬프트를 보존한다. 생성형 시안의 색·글자·광택은 확정 후 토큰과 실제 에셋으로 정리한다.

## 현재 프로젝트 기준

프로토타입과 개발 명세의 확정 테마는 여전히 클래식 / 스틸 포인트다. 기본값은 클래식. 이번 그래파이트·포레스트·에스프레소 비교안을 자동으로 설정 메뉴에 추가하거나 기본 팔레트를 변경하지 않는다. 선택 후 반영할 때도 최신 단순 지도, BT 아이콘, 릴, 좌우 이동, 패널 안의 카메라/저장 한 행과 자동 화면 표시 요구를 유지한다.
