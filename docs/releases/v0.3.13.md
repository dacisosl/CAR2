## 이번 버전 (0.3.13)
- **알림 소리 없이 바로 패널**: 시동을 끄면 패널만 뜹니다. ‘주차 층수를 기록하세요’ 알림은 화면을 띄우지 못했을 때(다른 앱 위에 표시 꺼짐 등)에만 올라옵니다. 이전에는 패널이 뜰 때마다 알림이 잠깐 같이 울렸습니다.
- **기압 측정 수정**: 패널이 뜨는 순간에도 기압계를 제대로 읽도록 측정을 따로 돌립니다. 측정값이 들어오면 층수 추천을 바로 다시 계산하고, 측정 전에 저장했어도 그 층을 기준점으로 남겨 다음 주차부터 추천에 씁니다.
- **시동만 껐다 켜면 원래 화면으로**: 패널을 만지기 전에 차가 다시 연결되면 패널이 닫히고 내비게이션 등 쓰던 앱(또는 잠금 화면)으로 돌아갑니다.
- **사이드바 아래 줄**: 상태바 칸을 내용에 맞는 길이(릴 폭)로 줄이고, 저장 버튼을 영상 아래 폭으로 넓혔습니다.
- **부드러운 영상**: 자동으로 열릴 때 지도는 패널을 닫거나 영상이 끝난 뒤 만들어, 주차 영상이 중간에 멈칫하지 않게 했습니다.
- 그 밖에: 취소된 패널을 닫다가 새 하차 패널을 잘못 닫을 수 있던 문제, 화면을 띄우지 못한 경우의 재연결 확인 누락을 고쳤습니다.

## 확인 방법
`adb logcat -s VehicleEvent AutoEntry`
- 시동 끄기 → `candidate … shown immediately, launch=true` → 약 1.5초 뒤 `pressure … hPa (… samples) → ATTACHED`
- 패널이 안 떴을 때만 `panel not shown — fallback notification posted`
- 시동만 껐다 켜기 → `AutoEntry: auto entry ended without user input — returning to the previous app`

- 알림음 없이 패널만 뜨는지, 시동만 껐다 켰을 때 내비게이션으로 돌아가는지
- 같은 주차장 두 번째 주차부터 층수 추천이 나오는지
