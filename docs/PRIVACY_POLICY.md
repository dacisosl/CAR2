# 주차기록 개인정보처리방침

시행일: 2026년 10월 3일 · 앱: 주차기록 (패키지 `app.car.parking`)

주차기록(이하 ‘앱’)은 계정 없이 동작하며, 이용자의 정보를 개발자 서버로 보내지 않습니다. 앱이 다루는 정보와 목적은 다음과 같습니다.

## 1. 휴대폰 안에만 저장하는 정보

| 정보 | 목적 | 보관 |
|---|---|---|
| 주차 층수, 감지·저장 시각 | 주차 기록 표시, 경과 시간 계산 | 앱 저장소(휴대폰) |
| 주차 위치(위도·경도·정확도·측정 시각) | 주차 위치 표시 | 앱 저장소 |
| 집 위치(사용자가 등록한 경우) | 집 근처 주차일 때 상태바 표시 기본값 결정 | 앱 저장소 |
| 등록 차량의 Bluetooth 기기 주소와 이름 | 등록 차량의 연결 해제만 감지 | 앱 저장소 |
| 사용자가 찍은 주차 사진 | 주차 위치 확인 | 앱 전용 폴더 |
| 기압 측정값 | 같은 주차장에서의 층수 추천 | 앱 저장소 |
| 디자인 테마, 사이드바 위치 등 설정 | 앱 화면 구성 | 앱 저장소 |

이 정보는 개발자나 제3자에게 전송하지 않습니다. 클라우드 백업과 기기 간 이전에서도 제외됩니다. 앱을 삭제하면 함께 삭제됩니다.

## 2. 권한과 사용 시점

| 권한 | 사용 시점 |
|---|---|
| 근처 기기(Bluetooth 연결) | 등록한 차량의 연결·해제를 확인할 때 |
| 위치(정확한/대략적) | 앱이 화면에 보이는 동안 현재 위치·주차 위치를 표시하거나 저장할 때. 백그라운드 위치 권한은 요청하지 않습니다 |
| 다른 앱 위에 표시 | 차에서 내렸을 때 앱 화면을 바로 띄우기 위해. 다른 앱 위에 창을 그리지는 않습니다 |
| 알림 | 상태바 층수 표시와, 자동 표시가 막혔을 때의 안내 |
| 카메라(시스템 카메라 앱 사용) | 사용자가 주차 사진 찍기를 누를 때만 |
| 부팅 완료 수신 | 재부팅 후 상태바 층수 표시 복원 |
| 인터넷 | 지도 표시(지도 기능이 연결된 경우) |

## 3. 외부 서비스

- **네이버 지도 SDK**(지도 키가 설정된 빌드): 지도 화면을 그리기 위해 네이버 서버에서 지도 데이터를 받습니다. 이 과정에서 기기·네트워크 정보와 표시 중인 지도 영역이 네이버에 전달될 수 있으며, 네이버 지도 Open API 이용약관과 네이버 개인정보처리방침이 적용됩니다.
- **Google Play 서비스 위치 API**: 휴대폰의 현재 위치를 얻는 데 사용합니다. Google 개인정보처리방침이 적용됩니다.

앱은 광고, 분석, 추적 SDK를 사용하지 않습니다.

## 4. 이용자의 선택

- 휴대폰 설정에서 언제든 권한을 거부하거나 철회할 수 있습니다. 위치를 거부해도 층수와 사진 기록은 사용할 수 있습니다.
- 앱을 삭제하면 휴대폰에 저장된 모든 기록과 사진이 삭제됩니다.

## 5. 아동

앱은 13세 미만 아동을 대상으로 하지 않습니다.
