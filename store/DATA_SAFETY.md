# Play Console 데이터 보안(Data safety) 응답

Play Console → 정책 및 프로그램 → 앱 콘텐츠 → **데이터 보안**. 아래는 Play에 올리는 **play 빌드**(`bundlePlayRelease`) 기준이며 코드와 빌드 결과물로 확인한 내용이다(2026-10-04).

## 근거: 앱이 기기 밖으로 보내는 데이터

Google 기준에서 ‘수집’은 앱(포함된 SDK 포함)이 데이터를 **기기 밖으로 전송**하는 것이다. 휴대폰 안에서만 처리·저장하는 데이터는 신고하지 않는다.

| 데이터 | 기기 밖 전송 | 근거 |
|---|---|---|
| 주차 층수·시각, 주차 위치 좌표, 집 위치 | 아니요 | Room·DataStore(앱 전용 저장소). 서버 없음. `dataExtractionRules`로 백업·기기 이전 제외 |
| 주차 사진 | 아니요 | 시스템 카메라 앱 → 앱 전용 폴더(`files/photos`). 업로드 없음 |
| 등록 차량 Bluetooth 주소·이름 | 아니요 | 기기 안에서 연결·해제 이벤트 비교에만 사용 |
| 기압 측정값 | 아니요 | 기기 안 층수 추천에만 사용 |
| 지도 표시 영역(주차 위치·현재 위치 주변), IP·기기 정보 | **예** | **네이버 지도 SDK**가 지도 데이터를 네이버 서버(`*.apigw.ntruss.com`, HTTPS)에서 받는다. 지도 카메라가 현재 위치·주차 위치를 따라가므로 요청 영역이 사용자의 위치를 나타낸다 |
| SDK 오류·진단 로그 | **예(가능성)** | 네이버 지도 SDK 안에 네이버 로그 수집 서버 주소(`nelo.navercorp.com`, HTTPS)가 들어 있다. SDK 오류 시 기기·OS 정보가 포함된 로그가 전송될 수 있다 |
| 현재 위치 계산 | 시스템 서비스 | Google Play 서비스 위치 API(Fused Location Provider). 앱은 결과 좌표를 기기 밖으로 보내지 않는다 |

- 광고·분석·추적 SDK 없음. 광고 ID(`AD_ID`) 권한 없음.
- GitHub 업데이트 확인은 github 빌드 전용이며 play 빌드에서는 실행되지 않는다(`SELF_UPDATE=false`).
- 지도 키 없이 빌드하면 지도가 ‘미연결’로 보이고 기기 밖 전송이 없다. 그러나 현재 빌드 환경(`android/local.properties`)에 지도 키가 있으므로 **아래 응답을 쓴다.**

> ⚠️ 네이버클라우드는 지도 SDK용 Play 데이터 보안 안내를 따로 공개하지 않는다(2026-10 확인). 아래는 SDK 동작을 보수적으로 가정한 응답이다. 네이버클라우드 고객 문의로 SDK가 보내는 항목(특히 기기 ID 여부)을 확인하면 그 답에 맞춰 고친다. 적게 신고하는 것은 정책 위반이고, 넉넉히 신고하는 것은 위반이 아니다.

## 1단계: 데이터 수집 및 보안

| 질문 | 응답 |
|---|---|
| 앱에서 필수 사용자 데이터 유형을 수집하거나 공유하나요? | **예** |
| 앱에서 수집하는 모든 사용자 데이터가 전송 중에 암호화되나요? | **예** (네이버 SDK 통신 HTTPS) |
| 사용자가 앱에서 계정을 만들 수 있나요? / 계정 생성 방법 | **내 앱에서는 계정을 만들 수 없음** |
| 데이터 삭제 요청 방법(URL) | 계정이 없어 필수 아님. 비워 두거나 개인정보처리방침 URL. 기기 데이터는 앱 삭제·앱 데이터 삭제로 지운다 |
| 독립 보안 검토(MASA) | 아니요 |

## 2단계: 데이터 유형

**선택하는 유형 (3개)**

| 카테고리 | 유형 | 수집 | 공유 |
|---|---|---|---|
| 위치 | 대략적인 위치 | ✔ | ✘ |
| 위치 | 정확한 위치 | ✔ | ✘ |
| 앱 정보 및 성능 | 비정상 종료 로그, 진단 | ✔ | ✘ |

- ‘정확한 위치’: 지도가 현재 위치를 확대해 보여 주므로 요청 영역이 3㎢보다 작아질 수 있다(Google 정의상 정확한 위치). 보수적으로 함께 신고한다.
- ‘공유 아님’: 네이버는 앱의 지도 표시를 위해 데이터를 받는 서비스 제공자이고, 개발자가 데이터를 받아 다른 곳에 넘기지 않는다.

**선택하지 않는 유형**: 개인 정보(이름·이메일·주소 등), 금융 정보, 건강 및 피트니스, 메시지, **사진 및 동영상**(기기에만 저장), 오디오, 파일 및 문서, 캘린더, 연락처, 앱 활동, 웹 검색 기록, 기기 또는 기타 ID(네이버 확인 전까지 근거 없음 — 확인 결과 ID를 보내면 추가).

## 3단계: 유형별 사용 방식

| 질문 | 대략적인 위치 / 정확한 위치 | 비정상 종료 로그 / 진단 |
|---|---|---|
| 수집됨 / 공유됨 | 수집됨 | 수집됨 |
| 임시로 처리되나요? | **아니요** (네이버의 보관 여부를 개발자가 보증할 수 없음) | **아니요** |
| 필수 / 선택 | **필수**(홈 지도는 끌 수 없음. 위치 권한을 거부하면 현재 위치 대신 저장된 위치만 표시) | **필수** |
| 수집 목적 | **앱 기능** | **앱 기능, 분석** |

## 4단계: 미리보기 후 저장

스토어에 ‘위치, 앱 정보 및 성능 수집 가능 · 제3자와 공유 안 함 · 전송 중 암호화 · 데이터 삭제 요청 불가(계정 없음)’ 정도로 표시된다. 개인정보처리방침 3절(네이버 지도 SDK)과 내용이 맞는지 확인한다.

## 다시 확인해야 하는 경우

- 지도 SDK를 바꾸거나 키 없이 빌드할 때
- 분석·오류 보고(Firebase Crashlytics 등)·광고 SDK를 추가할 때
- 사진 업로드, 백업, 공유 기능을 추가할 때
- github 빌드의 업데이트 기능을 play 빌드에 넣을 때(넣으면 안 됨)
