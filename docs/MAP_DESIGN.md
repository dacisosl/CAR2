# 지도 디자인과 연결 범위

버전 1.2 · 2026-10-03. 사용자의 새 지도 참조를 반영하되 앱 전체 UI를 재구성하지 않는다.

## 이번 단계

지도 영역만 교체한다. 기존 블랙·화이트 앱, 선택형 스틸 포인트, 홈 정보 순서, 층수 릴, 카메라-only/저장 한 행, 사이드바 좌우 이동을 유지한다. 지도 모습은 두 테마에서 동일하다.

포함: 단순한 실제 지도 스타일, 저장된 P 주차 핀과 층수 배지, 현재 위치 점과 정확도 범위, 지도 이동·확대, 현재 위치 재중앙 버튼. 도보 경로·예상 시간·실내 길찾기는 다음 단계다. 현재 버전에 임의 점선이나 ‘도보 4분’을 넣지 않는다.

이번 파일의 완료 범위: 수정 PNG, 오프라인 브라우저 지도 디자인·이동·재중앙 데모, Android 지도/GPS 구현 명세. 실제 Android SDK·GPS 연동이나 앱/APK 제작은 완료된 것이 아니다.

## 참조에서 가져올 것

| 요소 | 구현 기준 |
|---|---|
| 바탕 | 따뜻한 거의 흰색 `#F7F8F1` |
| 도로 | 흰색, 낮은 대비의 얇은 가장자리, 확대 수준에 맞는 폭 |
| 주변 영역 | 연한 회색·저채도 녹색, 세부 정보 절제 |
| 지명 | 현재 확대 수준에서 필요한 공원·주차장·주요 도로만 표시 |
| 주차 핀 | 블랙 P, 작은 흰 층수 배지 |
| 현재 위치 | 작은 파란 점, 흰 테두리, 실제 정확도에 대응하는 옅은 원 |
| 지도 틀 | 22dp 둥근 컨테이너, 기존 홈 지도 크기 유지 |
| 재중앙 | 오른쪽 아래 흰 원형 버튼, 최소 48dp 터치 영역 |

지도에 쓰는 공원 색과 현재 위치 파랑은 지리정보·위치 상태 표현이다. 앱 로고·브랜드 버튼에는 새 포인트 색을 추가하지 않는다. 실제 도로·건물의 위치와 형태를 예쁜 격자에 맞춰 왜곡하지 않는다. 참조의 둥근 블록은 시각 분위기이며 SDK에서 제공하는 스타일 범위 안에서 근접하게 구현한다.

## 실제 지도 구성

네이버 Android 지도 SDK의 커스텀 스타일을 우선 사용한다. 공식 스타일 에디터에서 색·정보량을 편집하고 발행한 스타일 ID를 `NaverMap.customStyleId`에 넣는다. SDK가 실제 지도 데이터를 불러와 이동·확대에 맞게 렌더링한다. 앱이 매 위치 이벤트마다 모든 도로·건물을 다시 다운로드하거나 직접 지도 엔진을 만들지 않는다.

`NAVER_MAP_KEY_ID`, `NAVER_MAP_STYLE_ID`는 구현 시 발급·설정할 별도 값이다. 이 패키지에는 실제 키나 발행한 스타일이 없다. SDK 로고·저작권 표시와 지도 컨트롤이 잘리지 않도록 패딩을 둔다. 커스텀 스타일 적용 시 지도 유형·레이어 그룹·실내지도·야간 모드 옵션은 스타일에 의해 고정되는 제약을 고려한다. 스타일 로딩 실패 시 지원되는 기본 지도에 주차/현재 위치 오버레이를 유지한다. 지도 인증·네트워크 실패에는 재시도 가능한 미연결 상태를 표시한다.

GPS/Android 위치 서비스는 좌표를 제공한다. 도로·건물은 지도 데이터, 위치 표시는 좌표, 이후 점선·예상 시간은 별도 보행 경로 데이터다. GPS만으로 보행 경로·지명이 생기지 않는다. 위치명은 조회 결과 또는 사용자 입력이 있을 때만 표시하고 모르면 ‘주차 위치’로 표시한다.

## 저장 위치와 현재 위치

`ParkingRecord`의 위치·측정 시각·정확도·출처는 확정 시 저장한다. 홈의 P 핀은 이 저장값을 따른다. 사용자가 걸어가는 동안 P 핀을 현재 위치로 옮기지 않는다.

현재 위치는 별도 `CurrentLocationState`로 유지한다. 화면이 활성 상태일 때 필요한 주기로 위치 업데이트를 요청하고 화면을 벗어나면 이 화면용 요청을 해제한다. 차량 감지 시점의 위치 수집 수명은 감지 기능에서 별도로 다룬다. 최초 표시에는 가용한 최신 위치를 받고, 오래된 마지막 좌표는 현재 위치처럼 보여주지 않는다. 권한·대략적 위치 여부·측정 시각·정확도로 `Locating / Available / Approximate / Stale / Unavailable`을 구분한다.

정확도 원은 실제 미터 오차 범위를 지도 투영에 맞게 나타낸다. 위치를 얻지 못하면 현재 위치 점을 숨기고 재중앙 버튼을 사용할 수 없는 상태로 설명한다. 저장 좌표가 있으면 주차 핀은 유지한다. 저장 좌표도 없으면 관련 위치 없음 상태를 표시하며 임의 P 핀을 넣지 않는다. 지하의 건물/입구·마지막 신뢰 좌표는 그 출처를 설명하고 정확한 주차 면이라고 표시하지 않는다. 층수·구역·사진은 계속 기록할 수 있다.

## 카메라와 제스처

홈 최초 진입에서는 저장 주차 위치를 중심으로 읽기 쉬운 확대 수준을 선택한다. 최신 현재 위치가 가까우면 두 점이 함께 보이게 범위를 조정할 수 있다. 기본은 2D·북쪽 위다.

재중앙은 최신 현재 위치를 중심으로 이동한다. 사용자가 지도를 드래그하면 자동 카메라 추적을 중단해 화면을 계속 끌어오지 않는다. 위치 점은 계속 갱신하고 재중앙을 누르면 추적을 다시 시작할 수 있다. 사이드바가 열리면 기존 배경 차단·릴 제스처를 유지한다. 테마 변경은 지도 위치·저장 기록을 초기화하지 않는다.

## 프로토타입과 PNG

`assets/map/map-demo.svg`는 실제 좌표가 없는 코드 기반 지도 그림이다. `prototype/index.html`에서는 드래그/방향키 이동과 현재 위치 재중앙의 디자인 동작만 확인한다. 브라우저 Geolocation이나 외부 지도·보행 API는 호출하지 않는다. 명확한 예시 표시를 유지한다.

`design/app-design-map-v1.2.png`가 최신 통합 시안이다. 실제 원본은 1672×941px이며 UHD 원본으로 표기하지 않는다. 기존 PNG들은 이전 레이아웃·브랜드 참고 자료다. 화면 검증은 사용자의 기존 요청에 따라 수행하지 않았다.

## Android 연결 순서와 완료 조건

1. 지도 SDK·등록 키와 스타일 ID 연결. 실제 국내 위치에서 도로·지명 품질과 참조 스타일을 비교한다.
2. 실제 저장 좌표·층수로 P 마커를 배치한다. 확정 기록 없을 때 상태도 처리한다.
3. 위치 권한·위치 업데이트를 연결하고 현재 위치/정확도 원을 갱신한다.
4. 재중앙·수동 탐색·라이프사이클·권한 거부·위치 없음·네트워크 실패를 처리한다.
5. 실제 기기에서 지도 데이터와 좌표가 일치하고 사용자 이동이 저장 핀을 바꾸지 않는지 확인한다.

도보 안내는 이후 별도 작업으로 두고 국내 보행 경로 품질·주차장 출입구 정보·비용을 확인한 뒤 도입한다. 경로 응답이 성공한 경우에만 실제 경로선·예상 시간을 표시한다.
