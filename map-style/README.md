# 네이버 지도 스타일 가이드 (주차기록)

네이버 클라우드 **Maps → Style Editor**에서 지도 모양을 앱 디자인에 맞추는 방법이다. 코딩은 필요 없고, 끝나면 **스타일 ID**만 개발 쪽에 넘기면 된다. 기준은 `docs/MAP_DESIGN.md`와 `design/tokens.json`의 `map` 값이다.

## 1. 내 라이브러리 아이콘 올리기

> 지도는 업로드한 SVG를 **그 픽셀 크기 그대로**(1px ≈ 1dp) 그린다. 80px 아이콘은 너무 크게 보이므로 지도에는 `icons-18px/`(18×18px)을 올린다. `icons/`(80px)는 원본·미리보기용이다. 크게 올렸다면 Quick Styling의 ‘아이콘 크기’로 줄여도 된다.

`map-style/icons/`의 SVG 13개를 **내 라이브러리**에 끌어다 놓는다.

| 규칙(네이버 공식) | 이 아이콘 |
|---|---|
| SVG 파일만 | SVG |
| 80×80px 이하 | 80×80px |
| 한 번에 50개, 계정당 200개까지 | 13개 |
| 한 스타일에서 아이콘 50개까지 교체 | 13개 |
| 아이콘 ID 단위로 바뀜(같은 ID를 쓰는 모든 장소에 적용) | — |

미리보기: `map-style/icons/preview.html`을 브라우저로 연다.

| 파일 | 바꿀 지도 아이콘 | 비고 |
|---|---|---|
| `car-parking.svg` | 주차장 | 흰 바탕 + 회색 P. 사용자가 저장한 **검정 P 핀**은 앱이 따로 그리므로 서로 구분된다 |
| `car-ev.svg` | 전기차 충전소 | |
| `car-gas.svg` | 주유소 | |
| `car-convenience.svg` | 편의점 | |
| `car-cafe.svg` | 카페 | |
| `car-restaurant.svg` | 음식점 | |
| `car-shopping.svg` | 쇼핑·백화점·마트 | |
| `car-hospital.svg` | 병원 | 저채도 버건디 |
| `car-pharmacy.svg` | 약국 | 저채도 버건디 |

## 3. 정보량 줄이기

- 장소(POI) 밀도: 낮게. 주차장·편의점·주유소·전기차 충전소·화장실은 남긴다.
- 끄거나 흐리게 할 것: 광고성 상호·체인 로고, 상세 건물 번호, 등산로·자전거길(주차 앱에 불필요).
- 지하철 노선: 얇고 옅게 남긴다.
- 3D 건물: 끈다(2D, 북쪽 위가 기본).
- 지도 로고와 저작권 표시는 숨기지 않는다(이용 조건).

## 4. 발행하고 앱에 넣기

1. 에디터에서 **발행(Publish)** → **스타일 ID**를 복사한다.
2. 개발 쪽: `android/local.properties`에 `NAVER_MAP_STYLE_ID=스타일ID`를 넣고 빌드한다. 저장소에는 올라가지 않는다.
3. 스타일을 불러오지 못하면 앱이 기본 지도로 바꾸고 ‘기본 지도’ 표시를 띄운다. 주차 핀과 현재 위치는 계속 보인다.

참고: [Map Style Editor 사용 가이드](https://guide.ncloud-docs.com/docs/application-maps-styleeditor-edit-vpc)
