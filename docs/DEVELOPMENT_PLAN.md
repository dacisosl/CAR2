# 제작 계획

실제 작업 시간은 환경과 실기기 테스트 결과에 따라 정한다. 이 계획은 시간 약속보다 선행 조건과 완료 기준으로 구분한다.

## 0. 시작 준비

- 이 폴더의 문서·시안·에셋을 확인한다.
- 테스트 휴대폰, OS, 차량 Bluetooth 이름/연결 방식, 기압 센서 지원을 확인한다.
- Android Studio·JDK·SDK와 현재 안정 Kotlin/Compose/AGP/Gradle 호환 조합을 정하고 기록한다.
- 재현 가능한 Android 프로젝트와 Gradle Wrapper를 생성한다. `android/` 디렉터리를 구현 작업의 기본 위치로 사용한다.
- 지도 API 키가 없어도 빌드 가능한 미연결 상태를 만든다.

완료: 깨끗한 checkout/압축 해제 환경에서 설명된 절차로 앱이 빌드되고 기본 화면이 설치된다.

## 1. 자동 표시 가능성 검증 — 가장 먼저

- 이미 페어링된 차량 선택, 등록 기기 식별과 이벤트 수신.
- 감지 서비스의 수명, 프로세스 종료·최근 앱 제거·재부팅·강제 중지 차이 확인.
- ‘다른 앱 위에 표시’ 설정 안내 및 권한 상태 확인.
- 서비스 시작 조건과 Activity 실행 조건을 별도로 검증. Android 15 이상에서 SAW 권한으로 백그라운드 FGS 시작 예외를 쓰려면 실제 보이는 overlay가 필요하다는 조건을 반영.
- 다른 앱 사용 중 앱 자동 표시, 화면 꺼짐 시 화면 켜기, 잠금 화면 위 Activity 표시를 실기기로 확인.
- 감지 테스트와 실제 차량 연결 해제 테스트를 분리해 기록.

완료: 지원 대상으로 정한 실제 기기에서 알림 탭 없이 화면 자동 표시가 재현되고 조건·실패 사례가 기록된다. 이 단계를 데모 클릭만으로 완료하지 않는다.

## 2. 디자인 구현

- 두 테마 토큰, 에셋, 홈, 처음 시작, 설정 화면.
- 설정의 클래식·스틸 포인트 미리보기 선택, 즉시 적용, DataStore 저장·복원. 자동 진입에도 동일한 테마 사용.
- 층수 릴, 추천 상태, 카메라-only+저장 작은 버튼 행.
- 패널 손잡이 드래그, 좌우 스냅, 위치 저장, 설정의 대체 선택.
- 320~430dp 폭과 큰 글자 배율에서 패널·버튼이 잘리지 않게 검증.
- 접근성 설명과 최소 48dp 터치 영역 확보.

완료: 최신 PNG의 정보 계층을 따르고 R02~R05, R09~R12, R15, R21 UI 조건이 동작한다.

## 3. 주차 후보와 저장

- 등록 차량만 필터링. 연결 해제 시 시간·센서·위치 상태 스냅샷.
- 기본 2초 재연결 확인(처음 6초에서 사용자 결정으로 단축), 후보 중복 방지.
- 후보와 확정 기록 분리. 저장 후 경과 시간·층수·사진·지도 갱신.
- 사진 선택기 연결, 앱 전용 저장 위치 또는 지속 접근권한 관리.
- Room 기록, DataStore 설정 복원.

완료: 재연결은 후보를 취소하고, 사용자가 저장하면 기록이 재시작 후 복원된다. 저장 전 기존 기록은 유지된다.

## 4. 지도 연결

- 네이버 SDK 등록 키와 커스텀 스타일 ID 준비, 최신 비용·조건 확인. `MAP_DESIGN.md`를 따른다.
- 새 참조의 배경·도로·라벨 정보량을 지원 범위 안에서 조정하고 SDK가 실제 지도를 렌더링하게 한다.
- 최신 현재 위치 점·정확도 원·재중앙 버튼과 화면 활성 수명의 위치 업데이트를 연결한다. 저장 P 핀과 현재 위치를 분리한다.
- 실제 좌표, 정확도, 수집 시각을 저장하고 지도와 P 핀에 반영.
- 지하에서 GPS가 나쁠 때 건물/입구 위치와 층수·구역·사진을 함께 사용.
- 키 없음·네트워크 없음·좌표 없음 상태 처리.

완료: 실제 지도와 저장 주차 위치가 표시되고, 최신 현재 위치·재중앙이 동작한다. 위치를 얻지 못해도 기록·층수 저장이 가능하다. 도보 경로·예상 시간은 이후 별도 단계다.

## 5. 기압 기반 층수 추천

- 기압 센서 존재 여부 확인, 허용된 실행 컨텍스트에서 주행/주차 중 측정.
- 방문 단위 최근 기준 기압과 알려진 기준층·층간 높이를 연결.
- 상대 높이 변화, 센서 안정성, 기준점 신뢰도로 추천 조건 결정.
- 기준 없음·기압 변화 불안정·센서 없음은 수동 선택.
- 확인한 층수를 보정 데이터로 저장하되 과거 날짜의 절대 기압을 새 방문 기준으로 그대로 사용하지 않음.

완료: 실제 주차장의 지상/지하 이동과 환경 변화에서 추천 품질을 측정한다. 근거가 없을 때 잘못된 확정 층수 대신 수동 선택을 표시한다.

## 6. 초기 설정·품질 마무리

- 차량 → 필요한 권한/실행 설정 → 자동 표시 테스트의 짧은 안내.
- 미완료 설정을 확인하고 필요한 단계로 직접 이동.
- 제조사별 백그라운드 동작, 잠금, 재부팅, 배터리 사용 측정.
- docs/ACCEPTANCE_TESTS.md의 항목별 결과와 미지원 조건 기록.
- 설치·실행 안내, 빌드 버전, 지도 키 설정 방법, 구현 변경사항 정리.

완료: 필수 요구사항이 실제 앱에서 검증되고 UI 데모와 네이티브 구현 결과가 구분되어 전달된다.
