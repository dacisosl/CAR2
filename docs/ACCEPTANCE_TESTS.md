# 검증 체크리스트

각 항목에 기기/OS, 조건, 실제 결과, 날짜를 기록한다. 미구현 또는 미검증을 통과로 표시하지 않는다.

## 디자인·UI

- [ ] 최신 CAR 로고 사용, 클래식·스틸에 맞는 측면 차량 에셋과 토큰 적용.
- [ ] 설정에서 두 테마 미리보기 카드 선택, 즉시 전체 화면 적용, 선택 상태 표시.
- [ ] 앱 재실행·자동 주차 진입에서도 테마 유지, 누락/잘못된 설정값은 클래식.
- [ ] 테마 변경 후 기록·사진·층수·타이머·BT 상태·패널 위치가 보존됨.
- [ ] 시스템 다크 모드 변경이 사용자 테마 선택을 바꾸지 않음.
- [ ] 홈에 ‘내 차 위치 보기’, ‘기록 수정’, Bluetooth 상태 텍스트 줄이 없음.
- [ ] 설정 옆 BT 활성/비활성 상태가 구분됨, 접근성 이름도 상태를 설명.
- [ ] 320/360/390/430dp 화면과 큰 글자에서 카드·버튼·지도가 잘리지 않음.
- [ ] 카메라는 아이콘만 표시, 카메라·저장 두 버튼이 같은 행·패널 내부.
- [ ] 최소 48dp 터치 영역과 TalkBack 이름 확인.
- [ ] 릴의 1F↔B1 전이가 정상이며 0F가 없음.
- [ ] 릴 스크롤은 층수만 변경하고 사이드바를 옮기지 않음.
- [ ] 손잡이 길게 누르기·반대쪽 드래그·놓기로 위치 이동.
- [ ] 유효 영역 밖에서 놓으면 원래 쪽 유지.
- [ ] 설정 위치 선택과 드래그가 일치, 앱 재실행 후 위치 복원.

## 차량 이벤트·자동 표시 — 실제 Android 기기 필수

- [ ] 등록 차량 이벤트만 처리, 이어폰/시계 해제에는 반응하지 않음.
- [ ] 확인 시간 내 재연결하면 후보와 화면 실행 취소.
- [ ] 재연결 없음 시 후보 하나만 생성하고 화면 자동 표시.
- [ ] 다른 앱 사용 중 알림 탭 없이 주차 앱 표시.
- [ ] 홈 화면/정상 백그라운드/최근 앱 제거의 결과를 각각 확인.
- [ ] 화면 꺼짐·잠금 상태에서 화면 켜기와 앱 표시.
- [ ] 보안 잠금 인증 흐름이 정상이며 잠금 해제를 우회하지 않음.
- [ ] 마지막 사이드바 위치가 자동 진입에도 반영됨.
- [ ] 권한 거부/권한 철회/서비스 중단 시 실제 준비 상태로 갱신.
- [ ] Android 버전별 FGS 시작과 Activity 실행 제한을 각각 검증.
- [ ] 재부팅·배터리 제한·제조사 정책의 지원 조건을 기록.
- [ ] 시스템 강제 중지 상태는 정상 백그라운드와 구분해 기록.

## 기록·사진·위치

- [ ] 후보 생성만으로 기존 확정 기록을 덮어쓰지 않음.
- [ ] 저장 시 최종 사용자 층수와 감지 시각 유지.
- [ ] 닫기 또는 사진 선택 취소가 확정 기록을 바꾸지 않음.
- [ ] 사진은 기록을 다시 열거나 앱 재실행한 뒤에도 접근 가능.
- [ ] 사진 보기/선택 시 잠금 상태의 시스템 인증이 정상.
- [ ] 위치 미지원·네트워크 없음에서도 층수와 사진 저장 가능.
- [ ] 오래된 좌표/낮은 정확도는 실내 주차 면으로 오인시키지 않음.
- [ ] 실제 지도 SDK, P 핀, 실제 저장 위치가 일치.

## 기압 추천

- [ ] 센서 없는 휴대폰에서 충돌 없이 수동 선택.
- [ ] 새 주차장·기준층 미상 상태에서 임의 층수를 확정하지 않음.
- [ ] 알려진 기준점에서 지상/지하 이동의 추천 품질 측정.
- [ ] 날씨/환기/장시간 간격/차량 실내 압력 영향 확인.
- [ ] 감지 이후 사용자가 계단으로 이동해도 주차 시점 측정 유지.
- [ ] 직접 릴 선택 후 늦은 추천이 선택을 바꾸지 않음.

## 이번 패키지 검증

이번 파일 패키지의 실제 결과는 루트 `VERIFICATION.md`에 기록한다. 위 목록은 앞으로 제작할 Android 앱의 완료 기준이다.

## 버전 1.2 지도 연결 기준 — 실제 Android에서 확인

- [ ] 실제 지도 데이터·커스텀 스타일 적용, 스타일 실패 시 지원되는 기본 지도 복구.
- [ ] 사용자 이동이 현재 위치만 갱신하고 저장 P 핀은 유지됨.
- [ ] 재중앙은 최신 현재 위치를 사용하고 수동 탐색 중 카메라를 강제로 끌어오지 않음.
- [ ] 위치 거부·대략적 위치·오래된 좌표·위치 없음·네트워크 실패의 상태가 구분됨.
- [ ] 화면을 벗어나면 화면용 위치 업데이트가 해제됨.
- [ ] SDK 로고·저작권과 48dp 재중앙 영역이 겹치지 않음.
- [ ] 실제 경로 API가 없는 이번 MVP에 임의 경로·도보 시간이 표시되지 않음.
